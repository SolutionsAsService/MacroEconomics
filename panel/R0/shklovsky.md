# Critic: Provocateur (Shklovsky), R0

**Anchor used:** Shklovsky, "Art as Technique": automatization devours perception; art exists "to make the stone stony" by defamiliarizing form and prolonging perception.

**Observed:** EVIDENCE.md: 12 files, no page, no README ("See the README for how to run or use what is here"). Data arrives pre-automatized: inflation rows "alphabetically from Aruba to Bangladesh"; oil as "304,000 million barrels" strings. A dump is the most automatized form there is; nobody perceives it. The plan risks the stock fintech dashboard (hero chart, cards, calculator), which is habit in a new coat. Two seeds of strangeness exist: Venezuela's three conflicting reserves (304,000 / 302,809 / 300,900) and the peg "1 euro = F.CFA 655.957", a number governing fourteen countries yet read as trivia.

**Verdict:** OBJECT. No device exists in the inheritance, and the plan names none.

**Requested change:**
1. Landing graphic must make one familiar quantity strange, e.g. one country's three oil figures drawn as bars that will not reconcile, or barrels as a volume beside a human figure. Not a ranked bar chart.
2. Each topic page withdraws one habitual frame: inflation as 100 units of purchasing power decaying, not a line; ports as the wait, not the rank.
3. Show EIA/OPEC/BP side by side; never average disagreement away. Pair the strangeness with a plain legend so it serves understanding.
4. Quadratic funding calculator: show each project's matching share shifting live, using the corrected rule.
5. Mark repaired and unsourced data openly on the about-the-data page.

**Statement of meaning:** The site should make readers see numbers they have stopped seeing, by letting the data's disagreements and units become its form.
